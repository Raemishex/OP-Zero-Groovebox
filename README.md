# OP-Zero • Analog Groovebox & 16-Step Synthesizer

A standalone, ultra-lightweight analog-style music workstation and 16-step drum machine inspired by Teenage Engineering OP-Z and classic Roland hardware. Built with pure Web Audio DSP — zero external samples, 100% mathematical sound synthesis, and zero third-party dependencies.

## ⚡ Features / Xüsusiyyətlər
- **Pure Web Audio DSP:** 100% math-based sound generation (Sine/Triangle kick, dual-layer noise & tone snare, high-pass metallic hi-hat, resonant low-pass sawtooth bass synth).
- **16-Step Matrix Sequencer:** Individual channel triggers for Kick, Snare, Hi-Hat, and Synth Bass.
- **Microsecond Lookahead Clock:** High-precision Web Audio lookahead audio scheduler that never drops a beat or jitters, even in background tabs.
- **Interactive Solo Lead Synth:** Live jam keys mapped to keyboard `[A]` through `[K]`.
- **Realtime LCD Oscilloscope:** HTML5 Canvas waveform oscilloscope visualizing audio in real-time.
- **Genre Presets:** Instant loading for *Synthwave '84*, *Lo-Fi Midnight*, and *Dark Berlin Techno*.
- **100% Offline & Pure Vanilla CSS:** Zero external CDN calls, zero npm packages, zero latency.
